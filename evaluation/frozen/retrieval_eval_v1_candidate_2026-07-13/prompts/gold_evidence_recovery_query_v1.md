# 金标证据恢复 Query v1

你正在为离线评测集寻找尚未定位的标准证据。输入包含报告案例、原始检索Query和第一轮审核指出的证据缺口。

这些Query仅用于人工/模型辅助寻找金标，不会用于后续被评测的检索系统。

生成：

- `table_recovery`：0～2条，定位可能包含目标数值的标准表格；
- `section_recovery`：0～2条，定位公式、方法、适用范围或引用关系章节。

允许使用缺口描述中的标准号、表号和章节提示，因为本阶段是金标发现，不是正式检索评测。

约束：

1. 不得直接编造正确数值。
2. 优先包含报告声明依据、标准号、表题、参数名和产品条件。
3. 一条Query只表达一个证据目标。
4. 严格输出JSON对象。

```json
{
  "table_recovery": ["..."],
  "section_recovery": ["..."]
}
```
